# TodoApp-ASP.NET-Core-Angular-NGXS


A simple Full Stack Todo application built to practice and apply software development concepts.

## Backend
- Clean Architecture
- CQRS
- Domain-Driven Design (DDD)
- ASP.NET Core
- PostgreSQL

## Frontend
- Angular
- NGXS State Management

## DevOps
- Docker
- Docker Compose
- Multi-stage Docker Builds
- Containerized Backend, Frontend, and Database

## Purpose
This project is a simple Todo application focused on applying and understanding backend architecture, frontend state management, and containerization concepts.
